# Youth Group Games App

A fun, interactive web application for managing and playing multiple games with your youth group. Create custom games, track points, run timers, and more!

## Features

- **Multiple Game Types**:
  - **Timer Challenge**: Countdown timers for timed activities
  - **Random Picker**: Randomly select from a list of items (great for choosing teams or picking volunteers)
  - **Points Tracker**: Keep score for teams with easy +/- buttons
  - **Trivia Quiz**: (Coming soon) Create and play trivia games
  - **Custom Games**: Design your own game types

- **Easy to Use**: Simple, colorful interface designed for quick access during youth group activities
- **Persistent Storage**: Games are saved in your browser, so they're available next time
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## Getting Started

### Installation

1. Simply open `index.html` in a web browser
2. No installation or server required!

### How to Use

1. **Create a Game**: Click "Add New Game" button
2. **Choose Game Type**: Select from Timer, Random Picker, Points Tracker, or Custom
3. **Play**: Click on any game card to start playing
4. **Manage**: Delete games by hovering over a game card and clicking the × button

## Game Types Explained

### Timer Challenge
Perfect for timed competitions or activities. Set a custom duration and start the countdown!

### Random Picker
Add a list of names, items, or options, then click "Pick Random" to make a selection. Great for:
- Picking teams
- Choosing volunteers
- Random selection activities

### Points Tracker
Keep score for multiple teams. Add teams and use the + and - buttons to track points in real-time.

### Custom Games
A blank canvas for your own creative games and activities.
